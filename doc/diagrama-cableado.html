Antes de energizar el circuito

!La línea ECHO necesita un divisor de voltaje

El pin ECHO del HC-SR04 entrega lógica de 5V; los GPIO del ESP32 solo toleran 3.3V. Coloca un divisor entre ECHO y el pin 26: una resistencia de 1kΩ desde ECHO hasta el nodo del GPIO, y una resistencia de 2kΩ desde ese nodo hasta GND, antes de conectarlo. Omitir este paso puede dañar el pin.

Limita la corriente de cada LED

Cada LED lleva su propia resistencia en serie con el ánodo (pata larga) — en este circuito se usaron resistencias de 220Ω. Nunca conectes un LED directamente entre un GPIO y tierra.
